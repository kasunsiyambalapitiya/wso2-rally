# Rally Backend (Go) Implementation Plan — Plan 1 of 4

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Go backend for WSO2 Motor Rally 2027 — a REST + WebSocket game engine that owns its own MySQL data, drives a config-driven 15-task rally, server-side geofencing and scoring, and a live leaderboard.

**Architecture:** A single `chi` HTTP service (`:8080`) plus a WebSocket hub on `/ws`. Two identities share one backend: organizer requests carry Asgardeo id tokens (validated via JWKS or decoded locally), participant requests carry backend-minted team-session JWTs; auth middleware routes by issuer. Domain packages under `internal/<name>/` mirror the customer-portal Ballerina `modules/<name>/` split (`handler.go`/`service.go`/`repo.go`/`types.go`/`constants.go`/`enums.go`). Persistence is `database/sql` + `go-sql-driver/mysql` behind repository interfaces; schema via `golang-migrate`.

**Tech Stack:** Go 1.23 · `github.com/go-chi/chi/v5` · `github.com/go-sql-driver/mysql` · `github.com/golang-migrate/migrate/v4` · `github.com/golang-jwt/jwt/v5` · `github.com/MicahParks/keyfunc/v3` · `github.com/coder/websocket` · `github.com/stretchr/testify` · stdlib `log/slog`, `crypto/rand`, `net/http/httptest`.

## Global Constraints

- **Go version floor:** 1.23. Module path `github.com/wso2-open-operations/wso2-motor-rally/backend` (adjust if the real org path differs — keep it consistent across all files).
- **License header:** every `.go` file starts with the Apache-2.0 header, `// Copyright (c) 2026 WSO2 LLC. (https://www.wso2.com).` block (see Task 1 for the exact text).
- **IDs:** all entity ids are 32-char lowercase hex, stored as `CHAR(32)`. Generate with `store.NewID()`.
- **Error responses:** every non-2xx JSON body is exactly `{"message": "<human sentence>"}`. Never leak internal error text to clients; log the internal error with `slog` + the actor id, return a safe message.
- **No silent fallbacks:** every DB/JWKS/parse error is either handled explicitly or returned; never swallow an error to return a zero value.
- **Naming:** package + file names are lower snake-free single words where possible (`events`, `taskengine`); Go identifiers are `CamelCase`; SQL columns are `snake_case`; enum string values are `snake_case`.
- **List endpoints** use `POST /<resource>/search` with a JSON body `{ "offset": int, "limit": int, "filters": {...} }`; default offset 0, limit 20, max limit 100.
- **`GET /health`** is unauthenticated and skipped by auth middleware.
- **TDD:** every task writes the failing test first, sees it fail, implements, sees it pass, commits. Unit tests (geo, taskengine, scoring, auth, httpx) need no DB. Repository/integration tests run against a docker MySQL and are gated on `TEST_DB_DSN` (skip with `t.Skip` when unset).

```go
package config

import (
	"fmt"
	"os"
	"strings"
)

type Config struct {
	Port                  string
	DBDsn                 string
	TeamTokenSecret       string
	JWKSEndpoint          string
	TokenValidatorEnabled bool
	AdminRole             string
	CORSAllowOrigin       string
	LogLevel              string
}

func Load() (Config, error) {
	c := Config{
		Port:                  getenv("PORT", "8080"),
		DBDsn:                 os.Getenv("DB_DSN"),
		TeamTokenSecret:       os.Getenv("TEAM_TOKEN_SECRET"),
		JWKSEndpoint:          os.Getenv("JWKS_ENDPOINT"),
		TokenValidatorEnabled: os.Getenv("TOKEN_VALIDATOR_ENABLED") == "true",
		AdminRole:             getenv("ADMIN_ROLE", "rally-admin"),
		CORSAllowOrigin:       os.Getenv("CORS_ALLOW_ORIGIN"),
		LogLevel:              getenv("LOG_LEVEL", "INFO"),
	}
	var missing []string
	if c.DBDsn == "" {
		missing = append(missing, "DB_DSN")
	}
	if c.TeamTokenSecret == "" {
		missing = append(missing, "TEAM_TOKEN_SECRET")
	}
	if len(missing) > 0 {
		return Config{}, fmt.Errorf("config error: missing required env: %s", strings.Join(missing, ", "))
	}
	return c, nil
}

func getenv(k, def string) string {
	if v := os.Getenv(k); v != "" {
		return v
	}
	return def
}
```

```go
// backend/internal/httpx/httpx.go  (Apache header)
package httpx

import (
	"encoding/json"
	"errors"
	"net/http"
)

type ctxKey string

const RequestIDKey ctxKey = "request-id"

var ErrMsg = map[string]string{
	"not_found":    "Resource not found.",
	"bad_request":  "Request could not be processed.",
	"unauthorized": "Authentication required.",
	"forbidden":    "You do not have access to this resource.",
	"conflict":     "That action conflicts with the current state.",
	"internal":     "Something went wrong. Please try again.",
}

func WriteJSON(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(v)
}

func WriteError(w http.ResponseWriter, status int, msg string) {
	WriteJSON(w, status, map[string]string{"message": msg})
}

func DecodeJSON(r *http.Request, dst any) error {
	if r.Body == nil {
		return errors.New("empty body")
	}
	dec := json.NewDecoder(r.Body)
	dec.DisallowUnknownFields()
	return dec.Decode(dst)
}
```

```go
// backend/internal/geo/geo.go  (Apache header)
package geo

import "math"

const earthRadiusM = 6371000.0

func HaversineMeters(lat1, lng1, lat2, lng2 float64) float64 {
	p1, p2 := lat1*math.Pi/180, lat2*math.Pi/180
	dLat := (lat2 - lat1) * math.Pi / 180
	dLng := (lng2 - lng1) * math.Pi / 180
	a := math.Sin(dLat/2)*math.Sin(dLat/2) +
		math.Cos(p1)*math.Cos(p2)*math.Sin(dLng/2)*math.Sin(dLng/2)
	return earthRadiusM * 2 * math.Atan2(math.Sqrt(a), math.Sqrt(1-a))
}

func PointInRadius(lat, lng, centerLat, centerLng, radiusM float64) bool {
	return HaversineMeters(lat, lng, centerLat, centerLng) <= radiusM
}
```

```go
// backend/internal/store/store.go  (Apache header)
package store

import (
	"context"
	"crypto/rand"
	"database/sql"
	"encoding/hex"
	"fmt"
	"time"

	_ "github.com/go-sql-driver/mysql"
)

func Open(dsn string) (*sql.DB, error) {
	db, err := sql.Open("mysql", dsn)
	if err != nil {
		return nil, fmt.Errorf("open db: %w", err)
	}
	db.SetMaxOpenConns(25)
	db.SetConnMaxLifetime(5 * time.Minute)
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	if err := db.PingContext(ctx); err != nil {
		return nil, fmt.Errorf("ping db: %w", err)
	}
	return db, nil
}

func NewID() string {
	b := make([]byte, 16)
	if _, err := rand.Read(b); err != nil {
		panic(err) // crypto/rand failure is unrecoverable
	}
	return hex.EncodeToString(b)
}

func InTx(ctx context.Context, db *sql.DB, fn func(*sql.Tx) error) error {
	tx, err := db.BeginTx(ctx, nil)
	if err != nil {
		return err
	}
	if err := fn(tx); err != nil {
		_ = tx.Rollback()
		return err
	}
	return tx.Commit()
}
```

```go
// backend/internal/store/migrate.go  (Apache header)
package store

import (
	"database/sql"
	"embed"
	"fmt"

	"github.com/golang-migrate/migrate/v4"
	"github.com/golang-migrate/migrate/v4/database/mysql"
	"github.com/golang-migrate/migrate/v4/source/iofs"
)

//go:embed migrations/*.sql
var migrationsFS embed.FS

func Migrate(db *sql.DB) error {
	src, err := iofs.New(migrationsFS, "migrations")
	if err != nil {
		return fmt.Errorf("migration source: %w", err)
	}
	drv, err := mysql.WithInstance(db, &mysql.Config{})
	if err != nil {
		return fmt.Errorf("migration driver: %w", err)
	}
	m, err := migrate.NewWithInstance("iofs", src, "mysql", drv)
	if err != nil {
		return fmt.Errorf("migrate init: %w", err)
	}
	if err := m.Up(); err != nil && err != migrate.ErrNoChange {
		return fmt.Errorf("migrate up: %w", err)
	}
	return nil
}
```

```go
// token.go core (Apache header)
package authz

import (
	"errors"
	"time"

	"github.com/golang-jwt/jwt/v5"
)

func MintTeamToken(secret, sessionID, vehicleID string, ttl time.Duration) (string, error) {
	claims := jwt.MapClaims{
		"iss": "rally-team", "sub": sessionID, "veh": vehicleID,
		"exp": time.Now().Add(ttl).Unix(), "iat": time.Now().Unix(),
	}
	return jwt.NewWithClaims(jwt.SigningMethodHS256, claims).SignedString([]byte(secret))
}

func VerifyTeamToken(secret, tok string) (Identity, error) {
	t, err := jwt.Parse(tok, func(t *jwt.Token) (any, error) {
		if _, ok := t.Method.(*jwt.SigningMethodHMAC); !ok {
			return nil, errors.New("unexpected signing method")
		}
		return []byte(secret), nil
	}, jwt.WithIssuer("rally-team"))
	if err != nil || !t.Valid {
		return Identity{}, errors.New("invalid team token")
	}
	c := t.Claims.(jwt.MapClaims)
	return Identity{Kind: "team", SessionID: str(c["sub"]), VehicleID: str(c["veh"])}, nil
}

func str(v any) string { s, _ := v.(string); return s }
```

## Task 21: `RequireOrganizer` requires the organizer group

**Milestone 1.** Every crew member now holds a valid Asgardeo token, which `middleware.Auth` classifies as `KindOrganizer`. Token *kind* therefore no longer separates staff from participants, and the organizer read surface — events, vehicles with full crew phone numbers, the live monitor — is gated on kind alone. Admin-only actions were already group-gated; the reads were not.

**Files:** `internal/config/config.go` (an `OrganizerRole` alongside `AdminRole`), `internal/middleware/auth.go`, `cmd/server/router.go`; tests alongside.

**Interfaces:** `RequireOrganizer(cfg)` becomes a constructor like `RequireAdmin(cfg)` and checks `identity.IsOrganizer() && authz.CheckRoles([]string{cfg.OrganizerRole}, identity.Groups)`. `ORGANIZER_ROLE` defaults to the same value as `ADMIN_ROLE` so an existing deployment keeps working, and `/sessions/join` sits in its own group so a crew member can still join.

- [x] **Step 5: Commit** — `git commit -am "fix(backend): gate the organizer surface on the organizer group"`

> **As built.** One trap worth recording: `authz.CheckRoles(required, have)` requires **every** role in
> `required`, so passing `[]string{OrganizerRole, AdminRole}` would have demanded membership of both. The
> gate uses a local `hasAnyRole` instead, which skips empty role names so an unset `ORGANIZER_ROLE` cannot
> become a group everyone is in. The test that distinguishes "organizer group" from "admin group" is what
> caught it. `ORGANIZER_ROLE` defaults to `ADMIN_ROLE`, so this fails **closed**: a deployment that has not
> configured a read-only organizer group ends up admin-only rather than open.
